SpareParts Co

A first-party subsidiary agent network of Fixpoint. This is not a shop — it is a published agent network that Fixpoint loads in the visitor's browser, after consent.

Peer URL: https://spareparts-fixpoint.vercel.app/spareparts

Shared action: check_stock(partId) → in-stock status, price and estimated arrival.
