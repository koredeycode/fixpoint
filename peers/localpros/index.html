Local Repair Pros

A first-party subsidiary agent network of Fixpoint. This is not a chat app — it is a published agent network that Fixpoint loads in the visitor's browser, after consent.

Peer URL: https://localpros-fixpoint.vercel.app/localpros

Shared action: available_slots(date?) → a list of bookable slots with ids, labels and prices.
